# Savora Restaurant

A full-stack restaurant ordering system with a React frontend and an Express backend.

## Project structure

- `front-end/` - Vite + React app
- `back-end/` - Express API server

## Features

- Customer menu browsing and product details
- Cart and checkout flow
- Order history and order tracking
- Admin dashboard and order management
- Authentication and role-based access
- Menu management for admins

## Getting started

### 1) Install dependencies

```bash
cd front-end
npm install

cd ../back-end
npm install
```

### 2) Run the frontend

```bash
cd front-end
npm run dev
```

### 3) Run the backend

```bash
cd back-end
npm run dev
```

### 4) Environment setup

Create `.env` files in the frontend/backend as needed and add your app configuration.
